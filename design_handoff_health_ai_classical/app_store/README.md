# App Store: иконка и витрина

Всё, что уходит в App Store Connect и в сборки, лежит в этой папке. Артборды,
из которых это выгружено, — в `../design/App Store и иконка.dc.html`
(идентификаторы `7a`–`7h`), описание знака — раздел 11 общего README.

## Иконка

Монограмма **H** гарнитурой Cormorant Garamond на бумажном фоне в золотом
кольце-паспарту, под знаком золотой штрих. Основной вариант — тёмный: на
светлом рабочем столе читается лучше светлого. Скругление углов накладывает
iOS, в PNG угол прямой.

| Файл | Размер | Куда |
| --- | --- | --- |
| `icon-1024-dark.png` | 1024 | Основной вариант, App Store Connect |
| `icon-1024-light.png` | 1024 | Светлый вариант, для печати и презентаций |

### iOS — `ios/AppIcon.appiconset/`

Готовый каталог ресурсов: скопировать целиком в
`HealthAI/Resources/Assets.xcassets/`, заменив существующий `AppIcon.appiconset`
(там сейчас зелёная иконка прежней темы). Xcode 15 и новее сам делает все
размеры из 1024.

| Файл | Появление | Что это |
| --- | --- | --- |
| `icon-1024.png` | any | Тёмный вариант знака — основной |
| `icon-1024-dark.png` | dark | Тот же знак: в тёмном режиме иконка не меняется |
| `icon-1024-tinted.png` | tinted | Серая шкала того же знака, тон накладывает система |

### Веб — `web/`

Те же файлы уже положены в `health-ai-frontend/public/`, отдельная копия здесь —
для передачи третьим сторонам.

| Файл | Размер | Где используется |
| --- | --- | --- |
| `favicon-16.png`, `favicon-32.png`, `favicon-48.png` | 16 · 32 · 48 | Вкладка браузера |
| `apple-touch-icon.png` | 180 | Ярлык на домашнем экране iOS |
| `icon-192.png`, `icon-512.png` | 192 · 512 | Манифест сайта |
| `icon-maskable-512.png` | 512 | Манифест, `purpose: maskable` — знак уменьшен на 10 % под обрезку Android |

## Витрина

Пять кадров 1290 × 2796 (iPhone 6,9″). Для 6,5″ те же артборды выгружаются
в 1242 × 2688. Тексты конечные, править только вместе с локализацией.

| Файл | Кадр | Заголовок |
| --- | --- | --- |
| `store-1-text-entry.png` | Запись еды текстом | Опишите словами — посчитает приложение |
| `store-2-diary.png` | Дневник | День целиком — еда и тренировки рядом |
| `store-3-report.png` | Вечерний разбор, тёмный кадр | Разбор дня, а не только цифры |
| `store-4-catalog.png` | Каталог продуктов | Ваши продукты — считаются без сети |
| `store-5-stats.png` | Итоги за месяц | Видно, куда идёт неделя и месяц |

Порядок кадров в App Store Connect — как в таблице: первым идёт то, чего нет у
других трекеров.

## Чего в папке нет

- Англоязычной версии витрины: тексты кадров пока только на русском.
- Кадров для iPad: приложение iPhone-only.
- Скриншотов для страницы поддержки — она текстовая.
