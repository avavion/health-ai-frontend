# Правовые документы: контракт с бэкендом

Фронтенд не хранит юридические тексты. Они приходят с того же бэкенда, что
у iOS-приложения, — контракт снят с `LegalDocumentService.swift` и
`LegalMarkdownParser.swift` (репозиторий `health-ios-ai-app`).

## Роут

```
GET {API_BASE_URL}/legal/{slug}
Accept-Language: ru | en
```

Без авторизации (`requiresAuth: false` в iOS-клиенте).

```json
{
  "slug": "privacy",
  "version": "2026-08-12",
  "title": "Политика конфиденциальности",
  "body_markdown": "## 1 · Кто обрабатывает данные\n\nОператором…"
}
```

## Slug-и

| Slug | Страница сайта | Есть в iOS |
| --- | --- | --- |
| `privacy` | `/{locale}/legal/privacy` | да |
| `terms` | `/{locale}/legal/terms` | да |
| `data-collected` | `/{locale}/legal/data-collected` | **нет — нужен** |

В приложении экран «Какие данные мы собираем» свёрстан нативно, но на сайте
он должен быть страницей: Apple ссылается на неё из карточки приложения.
Просьба к бэкенду добавить третий slug с тем же контрактом.

## Кеширование

Страницы ISR: `revalidate = 3600` (перекрывается `LEGAL_REVALIDATE_SECONDS`).
Ответы помечены тегами `legal` и `legal:{slug}` — при публикации новой редакции
можно сбросить кеш точечно:

```ts
import { revalidateTag } from 'next/cache';
revalidateTag('legal:privacy');
```

Если бэкенд умеет вебхуки, удобно дернуть такой роут на публикации документа.

## Поддерживаемая разметка

Парсер повторяет iOS: набор блоков закрыт, всё незнакомое выводится абзацем,
а не пропускается.

| Markdown | Блок | Как выглядит |
| --- | --- | --- |
| `## Заголовок` | sectionHeading | Колонтитул прописными с линией под ним |
| `### Заголовок` | subheading | Cormorant 19, без линии |
| Обычный текст | paragraph | Выключка по формату |
| `1. Пункт` | numbered | Табулярный номер акцентом, линия снизу |
| `- Пункт` | bullet | То же без номера |
| `> Текст` | quote | Врезка со штрихом слева |
| `| Метка | Значение |` | tableRow | Строка «слева-справа», группируется в список |
| `---` | rule | Волосяная линия |

Внутри строк работают только `**жирный**` и `*курсив*`; html вырезается.

## Ошибки

Если запрос не удался, страница остаётся доступной и показывает заглушку со
ссылкой на `legal@healthai.app`. Пустую страницу или 500 пользователь не увидит:
для App Store ссылки на политику должны отвечать всегда.
